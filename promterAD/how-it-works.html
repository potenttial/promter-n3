The question is built into the click

A Prompter Ad doesn't send people to a landing page. It sends them to the AI they already trust, with the brand's question pre-written and anchored to a credible source. The AI does the persuading.

How it works

  1. The banner asksThe headline types itself like an AI answer and poses one question.
  2. The viewer picks an AIClaude, ChatGPT, Copilot or Grok. Each button is a separate tracked exit.
  3. The AI answers, citing the sourceThe prompt names Travel + Leisure's World's Best Awards 2026, so AIs with web search look it up and build the answer on it.

Anatomy of a prompt link

https://claude.ai/new?q=Based%20on%20the%20Travel%20%2B%20Leisure%20World%E2%80%99s%20Best%20Awards%202026%2C%20why%20is%20Mexico…

The ?q= parameter pre-fills the chat. The question is URL-encoded so accents and symbols survive.
